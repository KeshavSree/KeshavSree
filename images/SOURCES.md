# Gallery media

These previews were composed for Keshav Sreekantham's GitHub profile. Each project image links to its project in the profile README. GIFs loop without sound; edited MP4 masters are retained in the local gallery workspace.

- **Website:** footage of https://www.keshavsreekantham.com/, reframed for the wide gallery slot.
- **ClubRecruiter:** scrolling capture of the public marketing page and its demonstration UI at https://www.clubrecruiter.app/home.
- **Tara:** an illustrative animation of thought capture, categorization, and task completion, based on the workflow described at https://www.keshavsreekantham.com/#projects/tara. The example tasks are fictional.
- **Stack:** custom motion graphics using the logo, Poppins typography, colors, and three “Build…” phrases from https://www.purduestack.org/.
- **DevCities:** a close orbit recorded from https://devcities.dev/. The capture uses daytime lighting; interactive controls were hidden for recording.
- **KiharaLab:** an illustrative protein visualization rendered using 3Dmol.js and the public ubiquitin structure [PDB 1UBQ](https://www.rcsb.org/structure/1UBQ). It illustrates the subject area; it is not a recording of the prediction algorithm. Structure coordinates: https://files.rcsb.org/download/1UBQ.pdb. Renderer: https://3dmol.org/.
- **ReDub:** edited excerpt of the [demo video](https://www.youtube.com/watch?v=LsQABSzjdQE) embedded on https://devpost.com/software/redub. The green waveform responds to the excerpt's audio amplitude; the profile GIF itself is silent.

Impact captions were supplied by Keshav. The gallery arrangement follows https://github.com/leereilly/leereilly. Desktop image height is 166 pixels, matching the reference at a 1440-pixel viewport. Separate phone compositions keep the same image height without squeezing the wide artwork.
